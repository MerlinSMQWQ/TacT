# TacT Agent Kit

Engineering guidance for developers working with agents: better delivery, useful judgment, and collaboration that keeps important decisions in the developer's hands.

Start with [the adoption guide](core/README.md) and [developer–agent collaboration](core/collaboration.md). The shared distribution unit is [AGENTS.md](AGENTS.md) plus `core/`; the adopting project owns `project/`.

This is the first English split edition. [The migration record](docs/migration.md) shows the source, changes, scoped verification, and remaining trial work. [The original English baseline](docs/baseline/AGENTS.en.md) remains available for comparison and fallback.
